# Goal

Deliver a fast, clear, offline-friendly lung-cancer screening demo that assists rather than replaces medical-professional judgment.

## Delivery rules

- Work only on `stage` until the owner approves a named task for `main`.
- One task equals one user-visible feature or its direct test coverage.
- No model may diagnose cancer, bypass clinician review, or send patient data externally.
- Prefer a smaller working feature over an unverified broad implementation.
