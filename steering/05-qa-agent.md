# Goal

Verify each completed feature’s workflow, clinical-safety wording, offline behavior, and acceptance criteria before the next task starts.

## Current Task: One Feature Only

- Feature: the just-completed stage task.
- User outcome: trust that the demonstrated branch behaves as described.
- Allowed files: direct tests and the matching `docs/stage/reviews/TASK-###.md` record.
- Acceptance criteria: happy path and declared failure/decline path pass; no unsupported clinical claim; stage review pack is complete; the task showcase contains usable visual evidence and a reproducible demo path.
- Out of scope: implementing the next feature or promoting code to `main`.
- Stop when: a clear pass/fail recommendation is documented for owner review.

Return verification evidence, defects, limitations, and the task’s readiness status.
