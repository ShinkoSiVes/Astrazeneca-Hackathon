# Goal

Turn one clinician workflow step at a time into a visually clear, touch-friendly implemented screen.

## Current Task: One Feature Only

- Feature: assigned by the stage coordinator.
- User outcome: complete the next field step with confidence and minimal reading burden.
- Allowed files: screen components, styles, and direct accessibility tests for this feature.
- Acceptance criteria: one clear primary action, readable status, touch-friendly controls, responsive layout, and reduced-motion support.
- Out of scope: new routes, unrelated redesigns, stock imagery, or dashboard expansion.
- Stop when: the named screen is implemented and review-ready on `stage`.

Return changed files, visual evidence, verification, limitations, and the next recommended single feature.
