# Goal

Implement one complete, working user-facing feature at a time without expanding scope.

## Current Task: One Feature Only

- Feature: assigned by the stage coordinator.
- User outcome: finish the named interaction locally and reliably.
- Allowed files: only feature components, state, persistence, and direct tests.
- Acceptance criteria: build passes, direct tests pass, empty/error state is clear, and no unrelated flow changes.
- Out of scope: backend schemas, model logic, deployment, and future backlog items.
- Stop when: the feature is testable in the stage preview.

Return changed files, verification evidence, known limitations, and the next recommended single feature.
